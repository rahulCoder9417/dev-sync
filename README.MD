# DevSync AI 🚀

DevSync AI is a collaborative cloud-based development platform that enables
real-time coding, terminal access, live preview, and team collaboration.

## Tech Stack
- Next.js (App Router)
- Express + WebSocket
- Prisma + PostgreSQL
- Clerk Auth
- RTK
- shadcn/ui
- xterm.js

## Features
- Real-time collaborative code editor
- Live preview with reverse proxy
- Cloud terminal sessions
- Team & project management
- File sync via WebSocket
