how terminal store and change data ====================================================================
. UI → Main Backend → Render Backend
When user performs file CRUD or edits content:
UI → sends change to Main Backend
Main Backend:
Updates DB
Sends update via WS to Render Backend to update disk
Main Backend broadcasts change to all connected users
Ensures DB + disk + UI stay aligned.
. Render Backend (Terminal) → Main Backend
When terminal commands modify files (mkdir, rm, npx create, npm install):
Node-PTY writes to disk
Render Backend detects changes
Sends file events to Main Backend via WS
Main Backend updates DB
main Backend broadcasts UI updates
Terminal changes become real DB changes and reflect in the UI.
